# 姓名學解析 App 開發與文案生成準則 (CLAUDE.md)

## 1. 專案核心目標與架構原則
本專案旨在開發一套具備現代心理學洞察力且閱讀體驗極佳的姓名學解析應用，支援**「個人姓名解析」**與**「雙人姓名合盤」**兩種核心模式，並採用**「核心基礎報告 ＋ Deep Talk 情境探索卡」**雙層架構。

* **【核心架構限制：零外部 API 依賴】**：
  * **嚴禁**在運行時（Runtime）串接任何外部 LLM API（如 OpenAI / Claude API）動態生成文案。
  * 所有康熙筆畫查詢、五格計算、生肖字根拆解、五行生剋權重與文案合成，必須在本地端（前端或自有後端）透過**「預建置靜態字典庫 ＋ 本地語意組裝引擎（Rule-based NLG Engine）」**瞬間完成，確保零延遲、零營運 Token 成本且 100% 離線可用。
* **【說明文案字數規範：單一說明區塊 150 字內】**：
  * 主體解析（`core_insight`）與情境盲點說明（`blind_spot_or_dynamic`）各自皆享有充足的 **150 字以內**發揮空間，讓具體生活場景與心理張力能被完整描繪，同時保持手機端閱讀的清爽感。

## 2. 階段一：自動化姓名學資料庫建置 (Build-Time Knowledge Base)
在開發期（Build-Time），請撰寫資料蒐集與清洗腳本，建置三份高度結構化的本地 JSON 靜態資料庫（全數轉換為自然流暢的台灣繁體中文）：

### A. 康熙字典與字根拆解庫 (`kangxi_dict.json`)
涵蓋台灣常用繁體中文姓氏與名字用字（至少 5,000 字），每筆字元需包含：
* `char`: 繁體中文字元
* `kangxi_strokes`: **強制使用康熙字典筆畫**（嚴格校正部首原畫數，例如：艸部算 6 畫、氵部算 4 畫、扌部算 4 畫、王字旁算 5 畫、辶部算 7 畫、阝在左算 8 畫／在右算 7 畫）。
* `wuxing`: 字義五行屬性（木、火、土、金、水）。
* `radicals_and_roots`: 拆字字根與隱含意象標籤陣列（例如：「芬」拆解為 `["艸(草木)", "八(分開)", "刀(武器)"]`；「家」拆解為 `["宀(屋簷洞穴)", "豕(豬)"]`），供生肖姓名學比對使用。

### B. 五格 81 靈動數與三才配置庫 (`numerology_81.json` & `sancai_wuxing.json`)
從網路公開姓名學資料庫萃取 1～81 數理與三才五行組合（如：木火土、金水木），清洗為**Slot-Ready（槽位化）**語意片段，確保組合後各說明區塊不超過 150 字：
* **現代心理學轉譯（去宿命恐嚇化）**：嚴禁直接搬運傳統「大凶、孤寡、破敗、短命」等恐嚇性字眼，必須在資料清洗期轉化為客觀的「性格盲點、高敏感特質、自我施壓傾向或人際課題」。
* **槽位欄位結構（配合 150 字說明上限）**：
  * `number_or_pattern`: 數理（1-81）或三才組合代碼
  * `energy_type`: 能量屬性（`auspicious` 順遂 / `challenging` 磨練 / `mixed` 雙面刃）
  * `hook_phrase`: 精煉特質標籤（限 15 字內）
  * `trait_clause`: 核心行為與心理描述子句（主詞省略，**限 55 字內**，兩項組合後加上連接詞剛好落在 150 字內）
  * `context_variants`: 針對不同領域的微調變體（皆**限 55 字內**：`general` 通用性格、`love` 感情互動、`work` 事業財運）
  * `shadow_trigger`: 壓力或衝突時的具體盲點與生活場景描述（**限 150 字內**）
  * `advice_snippet`: 具體可執行的日常建議短句（**限 40 字內**）

### C. 生肖喜忌字根對照庫 (`zodiac_rules.json`)
建立十二生肖（鼠至豬）與字根標籤的「喜用（加分/滋養）」與「忌用（耗損/衝突）」對照表（例如：虎喜 `["山", "林", "肉", "王", "衣"]`、虎忌 `["日", "口", "門", "蛇", "猴"]`）。

## 3. 階段二：姓名學計算與權重引擎 (Name Calculation & Weighting Engine)
演算法需精準執行以下計算，並依據「衝突強度與位置重要性」給予權重計分，僅提取最高權重的前 2～3 項送入文案組裝器：

### A. 個人姓名計算與權重規則
1. **五格與三才計算**：
   * **天格**：單姓＝姓＋1；複姓＝兩姓相加（原生家庭背景、長輩緣）。
   * **人格（核心權重 +35）**：單姓＝姓＋名一；複姓＝姓二＋名一（**主運**，核心個性、底層邏輯）。
   * **地格（核心權重 +30）**：單名＝名＋1；雙名＝名一＋名二（**前運**，內在安全感、親密關係）。
   * **外格（權重 +20）**：總格－人格＋1（單姓單名固定為 2）（社交面具、第一印象）。
   * **總格（核心權重 +30）**：全名康熙筆畫總和（**後運**，事業格局、財富與晚年穩定度）。
   * **三才五行生剋（權重 +25）**：取天、人、地格的「個位數」轉換為五行（1,2木、3,4火、5,6土、7,8金、9,0水），計算相生或相剋。
2. **生肖字位與字根分析（需輸入出生年並以立春分界換算生肖）**：
   * **姓氏（權重 +15）**：原生家庭支持度。
   * **名一（權重 +30）**：自我表達、感情態度與平輩人際。
   * **名二（權重 +30）**：執行力、工作表現、財庫與結果。

### B. 個人盤板塊映射（每板塊僅取權重最高的前 2～3 名配置）
#### 【第一層：核心基礎報告】
1. **個性與外在人設**：人格數理 ＋ 外格數理 ＋ 名一生肖字根。
2. **底層邏輯思考方式**：人格五行屬性 ＋ 天格與人格的五行生剋。
3. **面對壓力的顯現**：三才配置中的「相剋路徑」（如：天剋人、人剋地）。
4. **感情模式與親密需求**：地格數理 ＋ 名一生肖字根。
5. **工作天賦與財庫格局**：總格數理 ＋ 名二生肖字根。
6. **核心優缺點**：全名最和諧的五行相生／喜用字根 vs 最強烈的五行相剋／忌用字根。

#### 【第二層：Deep Talk 情境探索卡】
7. **面具與真實的反差感**：外格（別人眼中的你）vs 地格（私底下的內在小孩）。
8. **名字裡的「隱藏耗損點」與開運策略**：名字中出現「生肖忌用字根」或「數理過剛／過柔」的字位，提供具體日常行為調整建議。
9. **金錢觀與資源掌控力**：總格五行 ＋ 名二字根。

---

### C. 雙人姓名合盤映射 (Dual Name Compatibility)
計算雙方五格數理、三才五行與生肖字根的交叉互動（每板塊取權重最高的前 2～3 項）：
#### 【第一層：核心基礎報告】
1. **一起時的亮點與互補磁場**：雙方「人格五行」相生或比和 ＋ 字根互補生肖喜用。
2. **兩人需磨合的摩擦點**：雙方「人格五行」相剋，或「外格 vs 人格」相剋。
3. **內心世界與親密度方式**：雙方「地格數理與五行」的互動。
4. **關係的長遠發展與課題**：雙方「總格五行」互動 ＋ 彼此「天格與人格」交叉影響。

#### 【第二層：Deep Talk 關係探索卡】
5. **吵架與溝通地雷區**：比對雙方「外格（表達）」與「人格（核心自尊）」的生剋。
6. **最佳拍檔測試（室友／旅伴／合夥人）**：比對雙方「總格（目標）」與「名二（執行力）」。

## 4. 階段三：本地語意組裝與防呆引擎 (Rule-Based NLG Engine)
系統必須透過本地的**「動態句型組裝器（Sentence Assembler）」**合成報告，確保無 API 情況下依然流暢自然：

### A. 消除重複與生硬拼接 (Anti-Repetition)
* **全域已使用 ID 追蹤器 (`usedRuleIds`)**：維護已使用的數理或字根 ID。若「人格 21 數」已在「個性」板塊使用過 `general` 變體，在後續「工作」板塊再次被選中時，系統**強制切換**取用 `work` 變體；若無變體則順延取用次高權重項目，**嚴禁跨板塊重複**。
* **動態轉折連接詞庫**：
  * *當五行「相生／比和」時*：「在日常互動中，你不僅`{trait_1}`，內在更因為`{trait_2}`而獲得支撐，讓你的行動與想法能夠保持高度一致。」
  * *當五行「相剋／拉扯」時*：「外在表現上你往往顯得`{trait_1}`，但內心深處卻容易因為`{trait_2}`而感到緊繃——這種內外節奏的落差，常讓你在無形中自我拉扯。」

### B. 閱讀體驗與 150 字說明文案結構化輸出 (Readability & Word Limit)
* **白話心理轉譯**：內文完全使用現代心理學與行為描述，命理參數僅放在卡片底部的 UI Badge 標籤中。
* **結構化輸出與字數防呆檢核**：組裝引擎產出的各個說明區塊（`core_insight` 與 `blind_spot_or_dynamic`）皆放寬至 **150 字以內**，各欄位上限分配如下：
  ```json
  {
    "section_id": "name_persona_contrast",
    "section_title": "面具與真實的反差感",
    "hook_quote": "一句話金句（限 15 字內）",
    "core_insight": "主體解析：融合最高與次高權重配置，完整呈現心理特質與互動脈絡（嚴格限制 150 字內）",
    "blind_spot_or_dynamic": "具體日常盲點或互動場景說明：描繪在現實生活或關係衝突中會如何具體發生（嚴格限制 150 字內）",
    "actionable_advice": "一條具體可執行的日常建議（限 40 字內）",
    "name_tags": ["外格 12 畫（木）", "地格 15 畫（土）", "木剋土張力"]
